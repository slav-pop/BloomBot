# BloomBot Display Demo

Только экран + Wi-Fi/OTA/telnet. Без помпы, датчиков и сервера — ничего не уходит в Telegram.

Демо — это отдельное окружение PlatformIO **в том же проекте**. Оно собирает настоящие
`src/display.cpp`, `logger.cpp`, `wifi_ota.cpp`, `state.cpp` и свой `demo/display_demo/main.cpp`.
Копировать файлы не нужно: что поменял в `src/display.cpp`, то сразу и в демо, и в прошивке.

## Перед первой заливкой
1. `src/secrets.h` (из `src/secrets.h.example`): WIFI_SSID, WIFI_PASSWORD, OTA_PASSWORD — те же,
   что на ESP32 сейчас (иначе после заливки он уйдёт в другую сеть / с другим паролем OTA).
2. Переменная окружения `OTA_PASSWORD` = тот же OTA-пароль (как для `env:ota`).
3. Ноутбук подключить к той же сети (хот-спот), что и ESP32.

## Заливка
- По Wi-Fi: окружение `env:display_demo_ota` → Upload.
- По кабелю: окружение `env:display_demo` → Upload.
- Если `bloombot.local` не находится: в `upload_port` вписать IP ESP32 (список устройств в хот-споте телефона).
- **Вернуть настоящую прошивку:** окружение `env:ota` (или `env:esp32dev` по кабелю) → Upload.

## Команды (Monitor в `env:display_demo_ota` = telnet)
`0-6` настроение, `d` тур вкл/выкл, `+`/`-` влажность, `]`/`[` бак, `n` растение, `x` ошибка,
`f` время кадра и память, `i` Wi-Fi, `h` помощь.

Telnet принимает только одного клиента: второй (например, открытый Monitor в VS Code) выбивает первого.

**Перед тем как менять анимацию — прочитать `ANIMATION_LIMITS.md`.**

## Что показывает экран
| Настроение | Сцена |
|---|---|
| 0 IDLE (нет данных) | ночь, полумесяц, звёзды, цветок спит («z z z»), по стеблю ползёт божья коровка |
| 4 CONNECTING | закат, розовые облака, звёзды, значок Wi-Fi заполняется, цветок оглядывается |
| 5 OKAY | солнечный день, белые облака, пыльца, вокруг цветка летает бабочка, глаза следят за ней |
| 1 NEED_WATER | самая яркая сцена: оранжевое небо, большое солнце, марево, трещины в земле, цветок поник |
| 2 WATERING | свежее небо, жёлтая лейка поливает, вода бежит по стеблю, брызги, земля темнеет |
| 3 LOW_WATER | большая капля с мерцающим янтарным краем, внутри — уровень бака; цветок смотрит на неё |
| 6 ERROR | серые тучи, серый цветок, глаза «x x», большой красный знак «!», короткие помехи |

Всегда: облака плывут, цвет земли в горшке = влажность; при сухой земле лепестки опадают
(`-` несколько раз); после полива — прыжок и сердечко. Цветок — ромашка с круглыми лепестками,
цвет лепестков зависит от названия растения (`n`), без профиля — классический розовый.
В демо при LOW_WATER бак временно показывает 12 % (как в настоящей прошивке, там порог 20 %).

Безопасный режим: если ESP32 упал внутри кода экрана, после перезапуска экран пишет
«Display safe mode» и не анимирует, а Wi-Fi/OTA работают — исправление можно залить без кабеля.
Сбрасывается выключением питания или новой прошивкой.
